PROJECT OVERVIEW

The SK Dalagdag Portal is a web-based platform designed to provide residents and young people with easier access to announcements, projects, events, committees and other youth-related information.

The project focuses on creating a simple, mobile-friendly and organized digital space for the community.

Seat Reservation System

A digital seat reservation system created for organized event seating and registration.

VIEW PROJECT IMAGE ↗

PROJECT OVERVIEW

The Seat Reservation System was designed to simplify event seating by allowing users to select and reserve available seats through a digital interface.

The system was developed with an interactive seating layout representing tables and chairs, making event registration more organized and easier to manage.

SYSTEM FEATURES

  • Interactive Seating Layout
  • Table & Chair Arrangement
  • Seat Selection
  • Reservation Status
  • Event Registration
  • Digital Record Keeping
